# Demo assets

All company names, employees, contact details, biographies and logos are fictional. SVG logos and covers were created specifically for this demo. Portraits are illustrative stock portraits from Random User (https://randomuser.me/), downloaded from their static portrait collection. They do not depict the fictional employees. All images are bundled locally; no runtime image API is used. Social links point to platform homepages; portfolio links use example.com and email addresses use the reserved example.com domain.
